# Google Play 스토어 등록 문구

## 앱 이름

철근 물량 산출

## 짧은 설명

현장 철근 형상·가공길이·수량·중량을 빠르게 계산하고 저장합니다.

## 자세한 설명

철근 물량 산출은 철근 가공 현장 실무자를 위한 오프라인 계산 도구입니다.

주요 기능

- 일반철근과 보조철근 형상 선택
- A~G 구간 길이와 굽힘 각도 입력
- 철근 규격별 표준 단위중량을 이용한 kg 계산
- 공구·층·부재·전표별 프로젝트 관리
- 철근 행 추가, 삭제 및 순서 변경
- 프로젝트 자동 저장 및 `.rebar` 파일 내보내기/불러오기
- PC 버전과 프로젝트 파일 교환
- 인터넷 연결 없이 현장에서 사용

사용자가 입력한 프로젝트 데이터는 기기 또는 사용자가 선택한 파일에 저장되며 개발자 서버로 전송되지 않습니다.

주의: 계산 결과는 입력값을 기준으로 제공됩니다. 최종 발주·가공 전에는 현장 도면과 기준을 다시 확인하세요.

## 카테고리 제안

생산성

## 태그 제안

철근, 물량산출, 건설, 현장, 가공, 중량계산
